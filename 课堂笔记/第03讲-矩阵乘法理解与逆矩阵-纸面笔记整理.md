# 第03讲：矩阵乘法和逆矩阵

最开始学习矩阵乘法时，我记住的是一条计算规则：取左边矩阵的一行，再取右边矩阵的一列，对应相乘，然后相加。

这条规则足够让我算出答案，应付考试。不过，当时我看见的主要是计算步骤，还不太清楚整个乘法究竟在做什么。

这一讲，斯特朗从这条熟悉的规则开始，把同一个矩阵乘法从几个不同的角度重新看了一遍。算出的结果相同，但每一种看法会让我们注意到不同的关系。

## 一、先从一个元素算起

设两个矩阵相乘，得到矩阵 C：

```math
AB=C.
```

如果我们想求 C 中第 3 行、第 4 列的元素，也就是 c₃₄，就取 A 的第 3 行与 B 的第 4 列，将对应位置的元素相乘，再把这些乘积相加：

```math
c_{34}=a_{31}b_{14}+a_{32}b_{24}+\cdots+a_{3n}b_{n4}.
```

这里默认 A 至少有 3 行，B 至少有 4 列。换成一般的位置，就可以写成：

```math
c_{ij}=\sum_{k=1}^{n}a_{ik}b_{kj}.
```

i 指定结果的行，j 指定结果的列；中间的 k 从 1 变化到 n，负责把这一行与这一列中的元素逐个配对。

这个求和直接得到的是一个元素 cᵢⱼ。对 C 中的每个位置都这样计算，再把结果放回对应位置，就得到完整的 C。

### 为什么尺寸必须匹配？

取 A 的一行与 B 的一列计算时，两者必须有相同数量的元素，才能逐个配对。因此，A 的列数必须等于 B 的行数。

如果 A 是 m× n 矩阵，B 就可以是 n× q 矩阵：

```math
\underbrace{A}_{m\times n}
\underbrace{B}_{n\times q}
=
\underbrace{C}_{m\times q}.
```

A 有 m 行，B 有 q 列，所以结果有 m× q 个位置。

矩阵乘法不要求 A、B 都是方阵。如果它们恰好都是方阵，那么各自的行数又等于列数，尺寸匹配的要求就使它们必须具有相同的阶数。一般矩阵则只要求两个内侧的 n 相同，外侧的 m、q 可以不同。

这是我们最熟悉的计算方法。不过，如果始终盯着一个个元素，整列、整行之间的关系就容易被拆散。接下来，我们把它们作为整体来看。

## 二、一次看一整列

前面已经学过，矩阵右乘一个列向量，可以理解为：用这个向量中的数作为系数，对矩阵的各列做线性组合。

矩阵右乘另一个矩阵时，也可以沿用这个理解。

我们取一个简单例子，并在后面的讨论中继续使用它：

```math
A=\begin{pmatrix}
1&2\\
3&1
\end{pmatrix},
\qquad
B=\begin{pmatrix}
2&1\\
1&-1
\end{pmatrix}.
```

先只看 B 的第一列：

```math
A\begin{pmatrix}
2\\
1
\end{pmatrix}
=
2\begin{pmatrix}
1\\
3
\end{pmatrix}
+\begin{pmatrix}
2\\
1
\end{pmatrix}
=
\begin{pmatrix}
4\\
7
\end{pmatrix}.
```

这就是 C 的第一列。B 的第一列提供系数 2 和 1，让我们取 A 第一列的 2 倍，加上第二列的 1 倍。在这个过程中，B 的第二列没有参与。

再看 B 的第二列：

```math
A\begin{pmatrix}
1\\
-1
\end{pmatrix}
=
\begin{pmatrix}
1\\
3
\end{pmatrix}
-\begin{pmatrix}
2\\
1
\end{pmatrix}
=
\begin{pmatrix}
-1\\
2
\end{pmatrix}.
```

这就是 C 的第二列。把两个结果按原来的顺序并排放好，就得到：

```math
C=AB=\begin{pmatrix}
4&-1\\
7&2
\end{pmatrix}.
```

所以，可以把 B 看成 q 个列向量并排放在一起，用 A 分别乘以每一列，再把结果并排组成 C。整个过程都在重复我们已经理解的“矩阵乘列向量”。

这种看法也告诉我们：C 的每一列，都是 A 各列的线性组合；B 的对应列，告诉我们具体怎样组合。

## 三、一次看一整行

同一个乘法也可以按行来看。仍然使用刚才的 A、B，只不过这次由 A 的一行提供系数，对 B 的各行做线性组合。

A 的第一行是 (1,2)，所以 C 的第一行是：

```math
1(2,1)+2(1,-1)=(4,-1).
```

A 的第二行是 (3,1)，所以 C 的第二行是：

```math
3(2,1)+1(1,-1)=(7,2).
```

得到的仍然是：

```math
C=\begin{pmatrix}
4&-1\\
7&2
\end{pmatrix}.
```

因此，A 的每一行提供一组系数，用它们对 B 的各行做线性组合，得到 C 的对应行。C 的各行都是 B 各行的线性组合。

两种看法正好对应起来：按列看，B 的一列提供系数，组合 A 的各列；按行看，A 的一行提供系数，组合 B 的各行。

这里说的是“按列看”和“按行看”。实际运算分别是整个 A 乘以 B 的一列，以及 A 的一行乘以整个 B，并不是两个列向量或两个行向量直接相乘。

## 四、列乘行：收集一列对整个结果的贡献

第一种方法中，一行乘一列，得到一个数。如果把顺序换成一列乘一行，会得到什么？

比如：

```math
\begin{pmatrix}
2\\
3\\
4
\end{pmatrix}
\begin{pmatrix}
1&6
\end{pmatrix}
=
\begin{pmatrix}
2&12\\
3&18\\
4&24
\end{pmatrix}.
```

左边是 3×1 矩阵乘 1×2 矩阵，所以结果是一个 3×2 矩阵。

它的每一列都是左边列向量的倍数，每一行都是右边行向量的倍数。从几何上看，两个列向量都在经过原点与 (2,3,4) 的那条直线上；三个行向量都在经过原点与 (1,6) 的那条直线上。

一个列向量与一个行向量，就这样产生了一整个矩阵。那么，它与原来的 AB 有什么关系？

### 为什么是第 k 列乘第 k 行？

第四种计算方法，是取 A 的第一列乘 B 的第一行，再取 A 的第二列乘 B 的第二行，依次下去，最后把这些矩阵相加。

最初看到这里，我有一个疑问：第一种不是第 1 行乘第 1 列、第 1 行乘第 2 列……这样算过去吗？为什么这里却要按同一个编号配对？

只说“第一种得到一个元素，第四种得到整个矩阵”，还没有回答这个问题。我们需要看清，每一次列乘行得到的矩阵，究竟包含了什么。

回到前面的例子：

```math
A=\begin{pmatrix}
1&2\\
3&1
\end{pmatrix},
\qquad
B=\begin{pmatrix}
2&1\\
1&-1
\end{pmatrix}.
```

按第二种理解，C 的每一列都是 A 各列的线性组合。现在换个问题：A 的第一列，对整个 C 贡献了什么？

构造 C 的第一列时，B 第一列中的 2 告诉我们，要使用 A 第一列的 2 倍；构造 C 的第二列时，B 第二列中的 1 告诉我们，要使用 A 第一列的 1 倍。

这两个系数恰好组成 B 的第一行 (2,1)。把 A 第一列对两个结果列的贡献并排放好，就得到：

```math
\begin{pmatrix}
1\\
3
\end{pmatrix}
\begin{pmatrix}
2&1
\end{pmatrix}
=
\begin{pmatrix}
2&1\\
6&3
\end{pmatrix}.
```

这个矩阵已经与 C 一样大，但它只包含 A 第一列的贡献。

同样，B 的第二行 (1,-1) 告诉我们，A 的第二列在 C 的两个结果列中，分别使用 1 倍和 −1 倍。它对整个 C 的贡献就是：

```math
\begin{pmatrix}
2\\
1
\end{pmatrix}
\begin{pmatrix}
1&-1
\end{pmatrix}
=
\begin{pmatrix}
2&-2\\
1&-1
\end{pmatrix}.
```

把两列各自的贡献相加，才得到完整的 C：

```math
C=
\begin{pmatrix}
2&1\\
6&3
\end{pmatrix}
+
\begin{pmatrix}
2&-2\\
1&-1
\end{pmatrix}
=
\begin{pmatrix}
4&-1\\
7&2
\end{pmatrix}.
```

因此，每次列乘行，得到的都是 A 的某一列对最终 C 的整体贡献。

“整体”是说，这一项把该列对 C 所有列的贡献一次收集起来了；但它仍然只是一个来源的贡献，需要把 A 各列的贡献全部相加，才得到完整的 C。

为什么是第 k 列乘第 k 行，也从这里自然出来了：B 的第 k 行，记录的正是 A 第 k 列在各个结果列中的使用系数。它们是“被组合的那一列”与“属于它的整组系数”配在一起。

于是，这个过程可以概括成：

```math
C=AB=\sum_{k=1}^{n}
\bigl(A\text{ 的第 }k\text{ 列}\bigr)
\bigl(B\text{ 的第 }k\text{ 行}\bigr).
```

### 再回头看第一种方法

第一种方法逐个位置计算：

```math
c_{ij}=\sum_{k=1}^{n}a_{ik}b_{kj}.
```

一次求和得到一个元素。第四种则逐个来源计算，一次求和得到整个矩阵。

它们算出的结果相同，因为第四种中，A 第 k 列与 B 第 k 行的乘积，在 (i,j) 位置上的元素正是 aᵢₖbₖⱼ。把各列的贡献相加，每个位置上就完成了第一种方法中的求和。

第二种是问：“C 的这一列，怎样由 A 的各列组合出来？”第四种则是问：“A 的这一列，分别对 C 的各列贡献了什么？”同一个组合过程，换了收集贡献的方向。

## 五、分块乘法：把小矩阵作为计算单位

还可以把矩阵划分成若干块，每一块本身也是矩阵，再按块进行乘法。这有一种嵌套的感觉：我们把小矩阵作为计算单位，沿用“行乘列、乘积相加”的形式。

例如：

```math
A=\begin{pmatrix}
A_1&A_2\\
A_3&A_4
\end{pmatrix},
\qquad
B=\begin{pmatrix}
B_1&B_2\\
B_3&B_4
\end{pmatrix}.
```

结果可以写成：

```math
AB=
\begin{pmatrix}
A_1B_1+A_2B_3&A_1B_2+A_2B_4\\
A_3B_1+A_4B_3&A_3B_2+A_4B_4
\end{pmatrix}.
```

比如，左上角那一块就来自 A 的第一块行与 B 的第一块列。

不过，各块的尺寸必须正确匹配：相乘的两块必须能相乘，相加的两个结果也必须具有相同尺寸。而且块本身是矩阵，乘法顺序不能随意交换。不要求每块都是方阵，也不要求所有块一样大。

### 分块会让计算更省事吗？

单纯把一个普通矩阵切成四块，并不会自动减少运算量。原来的乘法和加法通常还是要做，只是组织方式变了。

比较容易看出好处的情况，是矩阵本来就有可以利用的结构。

比如，取两个 4×4 矩阵，它们的左上、右下各有一个 2×2 的非零块，另外两块都是零块：

```math
A=
\begin{pmatrix}
1&2&0&0\\
3&1&0&0\\
0&0&2&0\\
0&0&0&3
\end{pmatrix},
\qquad
B=
\begin{pmatrix}
2&1&0&0\\
1&-1&0&0\\
0&0&4&1\\
0&0&2&5
\end{pmatrix}.
```

把它们写成分块形式：

```math
A=\begin{pmatrix}
P&0\\
0&Q
\end{pmatrix},
\qquad
B=\begin{pmatrix}
R&0\\
0&S
\end{pmatrix}.
```

利用刚才的分块规则，直接得到：

```math
AB=\begin{pmatrix}
PR&0\\
0&QS
\end{pmatrix}.
```

左上角的 PR 就是前面已经算过的例子；右下角只需计算：

```math
QS=
\begin{pmatrix}
2&0\\
0&3
\end{pmatrix}
\begin{pmatrix}
4&1\\
2&5
\end{pmatrix}
=
\begin{pmatrix}
8&2\\
6&15
\end{pmatrix}.
```

因此：

```math
AB=
\begin{pmatrix}
4&-1&0&0\\
7&2&0&0\\
0&0&8&2\\
0&0&6&15
\end{pmatrix}.
```

这里的方便，是一眼看出零块使两部分不会互相混合，只需分别计算两个小矩阵乘积。逐个元素计算时也能跳过这些零项，而分块写法把这个结构直接显露出来了。

分块乘法在计算机计算中也有用途：计算机同样需要算法，数据与运算的组织方式也会影响计算过程。这里暂时不展开具体的优化方法。

这一种看法，把一组元素作为一块来处理。分块本身未必减少运算量，但可以让矩阵的结构更清楚，也方便利用这种结构进行计算。

## 六、逆矩阵：能不能撤销一个矩阵的作用？

接下来讨论逆矩阵，先从方阵开始。

对于一个方阵 A，它可能有逆，也可能没有。所谓有逆，是存在一个矩阵，记作 A⁻¹，使得：

```math
A^{-1}A=AA^{-1}=I.
```

I 是单位矩阵。这里的 A⁻¹ 是一个新的矩阵，不能理解成把 A 的每个元素分别取倒数。

对于方阵，如果一个矩阵左乘 A 得到 I，那么同一个矩阵右乘 A，也会得到 I。也就是说，方阵的左逆同时也是右逆。这里先使用这个结论，不展开它的证明；这并不是仅凭尺寸匹配就能得出的。

为什么乘出来要是单位矩阵？我们可以把它放回矩阵乘向量的过程中理解。

如果 A 把一个向量 x 变成 Ax，那么再乘以逆矩阵，就有：

```math
A^{-1}(Ax)=(A^{-1}A)x=Ix=x.
```

逆矩阵把 A 的作用撤销了，让我们回到原来的向量。从另一个顺序出发，也有 A(A⁻¹x) = x。

有逆的方阵叫作可逆矩阵，也叫非奇异矩阵；没有逆的方阵叫作奇异矩阵。

在讨论怎样求逆之前，先中断一下：为什么有些矩阵没有逆？

## 七、一个奇异矩阵的例子

取一个简单的方阵：

```math
A=\begin{pmatrix}
1&3\\
2&6
\end{pmatrix}.
```

关于它为什么不可逆，可以从不同的角度解释。我们先不使用行列式，而是用刚刚讨论过的矩阵乘法来理解。

### 从列的角度看：组合不出单位矩阵

假设 A 有逆，那么应该有：

```math
AA^{-1}=I.
```

按前面的列视角理解，乘积的每一列，都是 A 各列的线性组合。

但 A 的两列是：

```math
\begin{pmatrix}
1\\
2
\end{pmatrix},
\qquad
\begin{pmatrix}
3\\
6
\end{pmatrix}
=3\begin{pmatrix}
1\\
2
\end{pmatrix}.
```

它们在经过原点的同一条直线上。无论怎样线性组合，结果也只能落在这条直线上。具体来说：

```math
s\begin{pmatrix}
1\\
2
\end{pmatrix}
+t\begin{pmatrix}
3\\
6
\end{pmatrix}
=(s+3t)\begin{pmatrix}
1\\
2
\end{pmatrix}.
```

可是，单位矩阵的第一列是：

```math
\begin{pmatrix}
1\\
0
\end{pmatrix}.
```

它不在这条直线上，无法由 A 的两列组合出来。

因此，不论 A 右乘什么矩阵，结果都不可能是 I，A 也就没有逆。

### 从 Ax=0 看：一个非零向量被变成了零

还有一种解释。

对任何矩阵，Ax = 0 至少都可以取 x = 0。但这个解并不能告诉我们 A 是否可逆，因为所有矩阵都会把零向量变成零向量。

真正值得注意的是：有没有非零向量，也会被 A 变成零？

对于这个例子，可以取：

```math
x=\begin{pmatrix}
-3\\
1
\end{pmatrix}.
```

于是：

```math
Ax=
\begin{pmatrix}
1&3\\
2&6
\end{pmatrix}
\begin{pmatrix}
-3\\
1
\end{pmatrix}
=
\begin{pmatrix}
0\\
0
\end{pmatrix}.
```

现在假设 A⁻¹ 存在，对 Ax = 0 的两边左乘它：

```math
A^{-1}Ax=A^{-1}0.
```

左边变成 x，右边仍然是零，所以：

```math
x=0.
```

但我们选取的 x 明明是非零向量，矛盾。因此，逆矩阵不可能存在。

这个证明也把“无法撤销”说得更具体了：A 把零向量和这个非零向量，都变成了同一个零向量。再用一个矩阵乘以零，得到的仍然只能是零，不可能恢复出原来的非零向量。

这个推理并不局限于刚才的例子。对于任何方阵，只要能找到非零 x 满足 Ax = 0，就能这样证明它不可逆。

从列组合的角度说，就是各列能够用一组不全为零的系数组合成零向量。这里的“不全为零”，不要求每个系数都非零，只要求它们不能全部为零。

## 八、回到可逆矩阵：求逆就是按列解方程

现在回到可逆矩阵，换一个例子：

```math
A=\begin{pmatrix}
1&3\\
2&7
\end{pmatrix}.
```

这一次，两列不再处于经过原点的同一条直线上。我们试着求出一个矩阵，使它与 A 相乘得到 I。

设：

```math
A^{-1}=\begin{pmatrix}
a&c\\
b&d
\end{pmatrix}.
```

这里按列放置未知数，是为了把 AA⁻¹ = I 拆成两个已经熟悉的“矩阵乘列向量”：

```math
\begin{pmatrix}
1&3\\
2&7
\end{pmatrix}
\begin{pmatrix}
a\\
b
\end{pmatrix}
=
\begin{pmatrix}
1\\
0
\end{pmatrix},
```

```math
\begin{pmatrix}
1&3\\
2&7
\end{pmatrix}
\begin{pmatrix}
c\\
d
\end{pmatrix}
=
\begin{pmatrix}
0\\
1
\end{pmatrix}.
```

所以，求逆矩阵并没有突然变成一个完全陌生的问题。我们仍然是在解方程组，只不过两个方程组的系数矩阵相同，右端不同。

第一个方程组的解是逆矩阵的第一列，第二个方程组的解是逆矩阵的第二列。把它们并排放好，就得到逆矩阵。

对于 n 阶方阵，也是同样的思路：分别以单位矩阵的 n 列为右端，解 n 个具有相同系数矩阵 A 的方程组，得到逆矩阵的 n 列。

既然它们的系数矩阵相同，我们能不能把它们一起解？

## 九、高斯–约旦消元：把单位矩阵一起带着走

解一个方程组时，我们可以把右端接在系数矩阵后面，组成增广矩阵，对两边同时进行相同的行操作。

这里有两个右端，就把它们一起接上去。它们恰好组成单位矩阵，因此增广矩阵是：

```math
\left[\begin{array}{cc|cc}
1&3&1&0\\
2&7&0&1
\end{array}\right].
```

从第二行中减去第一行的 2 倍：

```math
R_2\leftarrow R_2-2R_1,
```

得到：

```math
\left[\begin{array}{cc|cc}
1&3&1&0\\
0&1&-2&1
\end{array}\right].
```

左半边已经是上三角矩阵 U。按照之前的高斯消元思路，到这里可以转向回代。但高斯–约旦消元会继续向上消元，把主元上方的元素也消掉。

从第一行中减去第二行的 3 倍：

```math
R_1\leftarrow R_1-3R_2,
```

得到：

```math
\left[\begin{array}{cc|cc}
1&0&7&-3\\
0&1&-2&1
\end{array}\right].
```

左半边变成了 I，右半边则是：

```math
A^{-1}=\begin{pmatrix}
7&-3\\
-2&1
\end{pmatrix}.
```

本例的两个主元恰好都是 1。如果主元不是 1，还需要把所在行除以主元，让它变成 1；必要时也可以交换行。目标都是把左半边化成单位矩阵。

于是，求逆的过程可以写成：

```math
[A\mid I]\longrightarrow[I\mid A^{-1}].
```

### 为什么右半边恰好就是逆矩阵？

我们可以先做一次乘法验证：

```math
\begin{pmatrix}
7&-3\\
-2&1
\end{pmatrix}
\begin{pmatrix}
1&3\\
2&7
\end{pmatrix}
=
\begin{pmatrix}
7-6&21-21\\
-2+2&-6+7
\end{pmatrix}
=
I.
```

不过，验证只说明这个结果确实正确。我们还要知道，为什么按照刚才的方法操作，右半边就会得到逆矩阵。

上一讲已经知道，行变换可以表示成左乘一个初等矩阵。连续做几步行变换，就相当于连续左乘几个初等矩阵。

把它们的乘积记作 E，那么整个消元过程就相当于：

```math
E[A\mid I]=[EA\mid EI].
```

注意，这里的 E 表示所有行操作合起来的矩阵，单位矩阵仍然记作 I。

我们对左半边做完消元，得到 I，因此：

```math
EA=I.
```

对于方阵，这说明 E 正是 A⁻¹。而右半边接受了完全相同的行操作，所以它变成：

```math
EI=E=A^{-1}.
```

这就是方法有效的原因。右半边原本放着 I，对它施加这些行操作，最终就把“所有行操作合起来的矩阵”显现出来了；而这些操作恰好把 A 变成 I，所以合起来就是 A 的逆。

在这个例子中，两次行操作对应的矩阵分别是：

```math
E_1=\begin{pmatrix}
1&0\\
-2&1
\end{pmatrix},
\qquad
E_2=\begin{pmatrix}
1&-3\\
0&1
\end{pmatrix}.
```

先做第一步，再做第二步，因此总的矩阵是：

```math
E=E_2E_1
=
\begin{pmatrix}
7&-3\\
-2&1
\end{pmatrix}
=A^{-1}.
```

所以，右半边得到的逆矩阵，是把 A 化成 I 的过程中自然产生的结果。我们也可以把整个过程看成同时解多个方程组：系数矩阵变成 I 时，右边各列就分别显露出各个方程组的解。

### 为什么这里采用行变换？

我们把右端接在 A 的右边，组成 [A | I]。每一次行操作都会同时作用于左、右两半，因此始终可以用“同一个矩阵 E 左乘两半”来解释。

不能把这个结论理解成“求逆矩阵禁止使用列变换”。列变换对应右乘矩阵，也有相应的方法。

例如，如果改成把 I 接在 A 的下方，对整个矩阵做相同的列操作，把 A 化成 I，合起来的右乘矩阵记作 F，那么：

```math
\begin{pmatrix}
A\\
I
\end{pmatrix}F
=
\begin{pmatrix}
AF\\
IF
\end{pmatrix}
=
\begin{pmatrix}
I\\
F
\end{pmatrix}.
```

因为 AF = I，所以 F 就是 A⁻¹，它会出现在下半边。

这里采用的是横向增广、统一做行变换的写法。关键是布局与操作相配合，让两部分始终经历相同的变换。
