# 从四维单纯形到四维超立方体：用自由度理解高维几何对象

> 《线性代数导论》第五版 · 习题 1.1 第 27 题延伸思考

## 导论：我最开始是这样想的

刚看到这道题的时候，我首先想到的是前面刚刚研究过的单纯形。

> 不是，我怎么想象的出来四维单纯形有多少个三维表面，等等，四维单纯形，应该是由四个向量所标定的点和原点界定的，那么这样的话，有五个标量，所以是五个三维表面，或者说三维单纯形。
>
> 同样地每个单纯形有多少个边呢？或者说多少个一维单纯形？一维单纯形只有一个自由度，所以是五个标量里面只有两个标量可以自由改变，其他都变成 0 了，那样就是排列组合 $C_5^2$。

但很快我发现，这道题里的对象其实根本不是单纯形。

我接着产生了这样的感觉：

> 四维超正方体和四维单纯形，是完全不同的东西。
>
> 就像之前说的那样，单纯形的感觉是那种你所说的“锥”，而超正方体显然不是那种“锥”，所以它是不同于单纯形的另一种四维模型。
>
> 但是这些模型底层是相同的，所以我好像知道，然后具体怎么算的是下一个话题。

等真正开始计算以后，我的思路又进一步变成：

> 对于超正方体（超正方体应该是特指四维的吧），它的每个顶点的坐标都有四个参数组合而成，因此，纯粹从四参数组合所有可能性的种类数角度出发，而不必考虑它们究竟是如何排列的，是 2 的四次方，也就是 16 个顶点。
>
> 另外，对于自由度，实际上我是从单纯形的角度才理解到的，不过依据你的描述，它似乎也可以通用。
>
> 线只有一个自由度，或者说，它只能在一个方向上变化，而不能改变其他方向。
>
> 这和单纯形又有所不同。单纯形确实提供了几个独立方向，但是某个向量上的方向概念并非是纯粹的；而在超正方体这种采用坐标系的模型中，显然方向是纯粹的。
>
> 对于边，由于坐标参数的方向具有纯粹性，所以我们可以还是单纯从坐标的可能种类数目下手，而无需担忧改变参数可能带来的其他方向的变动。
>
> 这样的话，就变成了一个简单问题：有四个数，现在需要从中选出一个可以改变的量，有四种可能；剩下三个参数尽管不变，但是有 8 种可能，所以最后得到 $4\times8=32$ 条边。
>
> 对于三维表面来说，是三个可以自由改变的变量和一个固定的恒定参数。这个恒定参数有四种可能，每种又有两个分支，所以最后可以得出 8 种。

这一连串想法里其实混着两个问题。

一个问题是：

> 四维单纯形和四维超立方体到底是什么关系？

另一个问题则是：

> 如果我根本无法直接想象四维几何对象，能不能只依靠参数、约束和自由度去理解它？

后一个问题才是这道题真正让我感兴趣的地方。

---

## 先把两个不同的四维模型分开

首先要修正一个术语。

“超立方体”（hypercube）并不是特指四维。

$n$ 维的立方体都可以称为 $n$ 维超立方体；四维的那个则是“四维超立方体”，也常称为 4-cube 或 tesseract。

我最开始把这道题和前面的四维单纯形联系起来，并不是毫无理由。

因为它们确实都是四维对象。

但是，同样是四维，并不意味着它们具有相同的结构。

四维单纯形是一种四维模型。

四维超立方体则是另一种四维模型。

这就像二维中，三角形和正方形都属于二维图形，却显然不是同一种东西。

三维中，四面体和立方体也都属于三维图形，却具有完全不同的顶点、边和表面结构。

把维数继续增加到四维，这个区别并不会消失。

---

## 我原来理解的单纯形是什么

前面讨论单纯形的时候，我使用的是：

```math
p=c_1v_1+\cdots+c_nv_n.
```

如果要求：

```math
c_i\ge 0
```

并且：

```math
c_1+\cdots+c_n\le 1,
```

那么可以再引入原点的权重：

```math
c_0=1-(c_1+\cdots+c_n).
```

于是：

```math
c_0+c_1+\cdots+c_n=1.
```

这时实际上有：

```math
O,\ v_1,\ldots,v_n
```

总共 $n+1$ 个顶点。

对于四维单纯形，也就是：

```math
O,\ v_1,\ v_2,\ v_3,\ v_4,
```

共五个顶点。

所以我最开始想到“五个三维表面”，其实并没有算错。

一个四维单纯形确实有五个三维单纯形作为它的边界。

同样，它的边由五个顶点中任选两个确定：

```math
\binom{5}{2}=10.
```

所以我的错误并不在于这套推理，而在于：

> 我把正确的“单纯形模型”，套到了错误的对象上。

题目问的是四维超立方体。

---

## 超立方体走的是另一套构造方式

标准四维超立方体可以直接写成：

```math
(x_1,x_2,x_3,x_4),
```

其中每个坐标分别满足：

```math
0\le x_i\le 1.
```

这和单纯形已经明显不同了。

对于单纯形，我一直在处理类似：

```math
c_1+c_2+\cdots+c_n\le 1
```

或者：

```math
c_1+c_2+\cdots+c_n=1
```

这样的关系。

几个系数之间存在一种整体约束。

如果某一个系数增大，其他系数还能活动多少就可能受到影响。

但对于超立方体：

```math
0\le x_1\le 1,
```

```math
0\le x_2\le 1,
```

```math
0\le x_3\le 1,
```

```math
0\le x_4\le 1.
```

四个坐标各自拥有自己的活动范围。

$x_1$ 在自己的区间中怎么变化，并不会要求 $x_2$ 必须跟着变化。

这正是我原话中所谓的：

> “坐标参数的方向具有纯粹性。”

这个词不是正式的数学术语，但它很好地记录了我当时的直觉。

更准确地说：

> 标准超立方体的各个坐标参数彼此独立，每一个参数分别对应一个独立的坐标方向。

---

## 顶点甚至完全不需要四维想象

现在重新看顶点。

一个四维超立方体中的点写成：

```math
(x_1,x_2,x_3,x_4).
```

如果它是顶点，那么每一个坐标都已经走到了自己活动区间的端点。

所以每个坐标只能是 $0$ 或者 $1$。

也就是说：

```math
x_i\in\{0,1\}.
```

这时根本没有必要知道四维超立方体“看起来是什么样”。

只需要数四个坐标一共有多少种组合。

第一个坐标有两种可能，第二个也有两种，第三个有两种，第四个仍然有两种。

所以：

```math
2\times2\times2\times2
=
2^4
=
16.
```

因此共有 **16 个顶点**。

这里我第一次明显感觉到：

> 对于超过直观能力的高维对象，也许没有必要执着于先把它“画出来”。

我可以直接研究描述这个对象的参数。

---

## 从单纯形带过来的“自由度”

顶点其实还比较容易。

真正让我觉得前面的学习开始发生迁移的是“自由度”。

这个想法我最开始是在单纯形里逐渐建立起来的。

例如：

```math
c+d+e=1.
```

虽然写了三个变量，但如果 $c$ 和 $d$ 已经确定：

```math
e=1-c-d
```

也自动确定了。

所以实际上只有两个参数可以独立变化。

因此得到的是一个二维对象。

从这里我逐渐形成了一种感觉：

> 一个对象有多少维，可以去看它有多少个真正独立的变化方向。

现在到了超立方体，这个想法依然可以使用。

而且由于坐标彼此独立，它反而变得更加直接。

---

## 一条边只有一个自由度

一条线是一维的。

所以一条边应该只能有一个真正能够自由变化的参数。

例如：

```math
(t,0,1,0),
\qquad
0\le t\le1.
```

这里第二、第三、第四个坐标都已经固定。

只有第一个坐标可以变化。

所以这个点只能沿一个方向移动。

这正是我原话中的：

> “线只有一个自由度，或者说，它只能在一个方向上变化，而不能改变其他方向。”

在标准超立方体中，这句话非常容易直接落实到坐标上。

---

## 于是数边变成了数参数状态

四个坐标中，需要选出一个作为自由变量。

有 $4$ 种可能。

比如可以是：

```math
(t,x_2,x_3,x_4),
```

也可以是：

```math
(x_1,t,x_3,x_4),
```

等等。

剩下三个坐标虽然不能变化，却仍然需要决定它们固定在哪里。

每一个固定坐标都有两种可能：$0$ 或者 $1$。

所以三个固定坐标共有：

```math
2^3=8
```

种组合。

于是：

```math
4\times8=32.
```

最终得到 **32 条边**。

我觉得这一步真正有意思的是：

> 一个坐标负责决定“沿哪个方向变化”，剩余坐标负责决定“这条边处在什么位置”。

因此整个问题根本不要求我真正看见 32 条边。

只需要数参数状态。

---

## 三维表面也是同样的问题

接下来是最开始最难想象的部分：

> 四维超立方体到底有多少个三维表面？

如果继续要求自己想象：

> “一个四维东西的外面到底包着多少个三维立方体？”

我基本没有可靠的空间直觉。

但从自由度来看，这件事已经没有什么特别神秘的地方了。

一个三维对象需要三个自由参数。

四维超立方体一共有四个坐标。

所以一个三维表面应该：

> 让三个坐标继续自由变化，只固定其中一个坐标。

例如：

```math
(x_1,x_2,x_3,0).
```

前三个坐标都可以满足：

```math
0\le x_1,x_2,x_3\le1,
```

第四个坐标则始终保持：

```math
x_4=0.
```

前三个自由参数本身就构成了一个普通的三维立方体。

所以这确实是四维超立方体的一个三维表面。

现在只需要数：

> 到底固定哪个坐标？

共有 $4$ 种选择。

而被固定的那个坐标又可以固定成 $0$ 或者 $1$。

所以每一种又分成两个分支。

最终：

```math
4\times2=8.
```

也就是 **8 个三维表面**。

这正对应我最开始那句话：

> “三个可以自由改变的变量和一个固定的恒定参数，这个恒定参数有四种可能，每种又有两个分支。”

---

## 到这里，我其实已经不再试图“看见”四维超立方体

这可能是这道题对我最有价值的地方。

最开始我的问题是：

> 四维的东西，我怎么可能想象得出来？

后来我发现，这个问题可能本身就没有那么重要。

因为对于标准四维超立方体，我只需要知道：

```math
(x_1,x_2,x_3,x_4),
```

并且：

```math
0\le x_i\le1.
```

剩下的事情可以完全从自由度出发。

- 顶点没有任何自由参数；
- 边有一个自由参数；
- 二维面有两个自由参数；
- 三维面有三个自由参数；
- 完整的四维超立方体有四个自由参数。

也就是说：

> 几维对象，就对应保留几个可以独立变化的坐标。

至少对于这种坐标结构非常规则的对象来说，这个视角非常直接。

---

## 单纯形和超立方体虽然不同，但自由度可以跨过去

现在再回头看我之前说的：

> “这些模型底层好像是相同的。”

这句话如果直接说，实际上有点含糊。

因为单纯形和超立方体当然不是同一种几何结构。

它们的顶点数量不同。

边的组织方式不同。

参数之间的约束方式也不同。

真正相同的，是我现在观察它们的方式。

对于单纯形，我问：

> 有多少参数？  
> 它们之间有什么约束？  
> 约束以后还剩多少真正可以独立变化的参数？

对于超立方体，我同样在问：

> 哪些坐标可以自由变化？  
> 哪些坐标必须固定？  
> 最后还剩几个真正可以独立变化的方向？

所以真正能够从一种模型迁移到另一种模型的，不是它们具体的形状，而是：

> 参数 → 约束 → 自由度 → 几何维数

---

## 再往前一步：其实可以直接得到一般情况

现在四维已经不特殊了。

考虑一个 $n$ 维超立方体：

```math
[0,1]^n.
```

如果要找其中一个 $k$ 维面，就需要 $k$ 个可以自由变化的坐标。

首先从 $n$ 个坐标中挑出这 $k$ 个：

```math
\binom{n}{k}.
```

还剩：

```math
n-k
```

个坐标必须固定。

而每一个固定坐标都有 $0$、$1$ 两种选择。

所以这些固定坐标总共有：

```math
2^{n-k}
```

种状态。

因此：

```math
N_{n,k}
=
\binom{n}{k}2^{n-k}.
```

这里的公式已经不太需要死记。

它实际上只是把前面的自然语言压缩了：

> 先选出哪些坐标可以动，再决定剩下的坐标分别固定在哪一端。

对于四维超立方体：

| 对象 | 自由度 | 数量 |
| --- | ---: | ---: |
| 顶点 | 0 | $\binom{4}{0}2^4=16$ |
| 边 | 1 | $\binom{4}{1}2^3=32$ |
| 二维面 | 2 | $\binom{4}{2}2^2=24$ |
| 三维面 | 3 | $\binom{4}{3}2=8$ |
| 四维超立方体本身 | 4 | $\binom{4}{4}=1$ |

---

## 最后

这道题最开始给我的感觉是：

> 我无法想象四维，所以这个问题很难。

但现在反而变成了：

> 正因为我无法可靠地想象四维，所以我才开始真正依赖参数、约束和自由度。

而这个“自由度”的想法并不是从这道题凭空出现的。

它是我在前面的单纯形中，为了理解为什么

```math
c_1+\cdots+c_n=1
```

会让维数减少一维，而逐渐形成的。

到了这道题，它第一次被迁移到了另一种完全不同的高维模型中。

所以现在对我来说，四维单纯形和四维超立方体依然是两种完全不同的东西。

但是我不再需要为每一种高维模型单独创造一种直觉。

我可以先问：

> 参数能够怎样变化？

再问：

> 其中究竟有多少个真正独立的变化方向？

有时候，这已经足够代替“我到底能不能把它想象出来”。
