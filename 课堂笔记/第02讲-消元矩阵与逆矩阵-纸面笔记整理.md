# 第02讲：消元矩阵与逆矩阵

接下来我们要讨论的是：如何使用消元法求解线性方程组。

事实上，尽管消元法看起来其貌不扬，但是实际上所有计算机程序用到的都是这种方法。只要方程组的矩阵 $A$ 满足特定要求，成为一个好矩阵，那么消元法就能顺利解出来。至于消元法无法解出的情况，不是今天探讨的课题。

最后我们要做的是用矩阵语言描述消元法，毕竟我们学的是线性代数，总要回归到其核心概念——矩阵变换上。

不过，在此之前，我们先用传统方法来进行消元。

```math
\begin{cases}
x+2y+z=2\\
3x+8y+z=12\\
4y+z=2
\end{cases}
```

为了避免令人不悦的加减号等符号，我们用矩阵简记过程：

```math
A=
\begin{bmatrix}
1&2&1\\
3&8&1\\
0&4&1
\end{bmatrix}
```

> 现在时候未到，我们先不管向量 $b=(2,12,2)$ 。MatLab 也是先算左侧矩阵，然后再回来算右侧向量。

针对 $x$ 进行消元，我们可以把 $A$ 第一列的 $1$ 称为主元，它们是消元的关键。

第一个主元：

```math
\begin{bmatrix}
\boxed{1}&2&1\\
3&8&1\\
0&4&1
\end{bmatrix}
```

主元行不变。

用 2 行减去 3 个 1 行，因为消去的是 $(2,1)$ 元素，所以会用 $(2,1)$ 代称这一步：

```math
\begin{bmatrix}
1&2&1\\
3&8&1\\
0&4&1
\end{bmatrix}
\longrightarrow
\begin{bmatrix}
1&2&1\\
0&2&-2\\
0&4&1
\end{bmatrix}
```

> 如果是 MatLab，还有 $(3,1)$ 。即使 $(3,1)$ 本来就为 $0$ ，它也要把第三行的 $x$ 系数消去。

对于我们来说，现在当然是处理第二个主元下面的元素。

```math
\begin{bmatrix}
1&2&1\\
0&\boxed{2}&-2\\
0&4&1
\end{bmatrix}
```

也就是消去 $(3,2)$ ：

```math
\begin{bmatrix}
1&2&1\\
0&2&-2\\
0&4&1
\end{bmatrix}
\longrightarrow
\begin{bmatrix}
1&2&1\\
0&2&-2\\
0&0&\boxed{5}
\end{bmatrix}
```

主元 3 下面没东西了，所以不用再消了。

---

从矩阵

```math
A=
\begin{bmatrix}
1&2&1\\
3&8&1\\
0&4&1
\end{bmatrix}
```

通过消元得到的矩阵

```math
\begin{bmatrix}
1&2&1\\
0&2&-2\\
0&0&5
\end{bmatrix}
```

被记为 $U$ 。

$U$ 表示上三角矩阵。

即消元的目的是从 $A$ 得到 $U$ 。

这是计算科学中最普遍的运算。由于其很普遍、很重要，所以人们也在思考有没有更快的算法。但是今天我们不看那些更快的算法，因为它们都没有上面这种消元法直观。

这里顺便提一下，主元是不能为 $0$ 的。上面这个矩阵就很好，主元就是：

```math
1,\quad 2,\quad 5
```

不需要做额外运算。

由于 Strang 经常用到日后才能学到的知识，这里也稍微提一下行列式：

```math
A\text{ 的行列式}=\text{主元之积}
```

即：

```math
1\times2\times5=10
```

下面我们讨论那些不是那么“顺利”的情况，然后再回来。

消元失效，其实简单来说就是在说得不到三个主元。

当主元 1，也就是第一个主元，是 $0$ 时，其实就已经有些麻烦了：

```math
\begin{bmatrix}
\boxed{0}&2&1\\
3&8&1\\
0&4&1
\end{bmatrix}
```

但这种麻烦还能够解决，我们可以通过行交换来让 $3$ 成为主元 1。

又或者，把 $(2,2)$ 从 $8$ 改成 $6$ ：

```math
\begin{bmatrix}
1&2&1\\
3&6&1\\
0&4&1
\end{bmatrix}
\xrightarrow{(2,1)}
\begin{bmatrix}
1&2&1\\
0&\boxed{0}&-2\\
0&4&1
\end{bmatrix}
```

但是同样的，还可以通过行交换来解决。

但如果下面没元素，那就没办法了。

比如把 $(3,3)$ 由 $1$ 改成 $-4$ ：

```math
\begin{bmatrix}
1&2&1\\
0&2&-2\\
0&4&-4
\end{bmatrix}
\xrightarrow{(3,2)}
\begin{bmatrix}
1&2&1\\
0&2&-2\\
0&0&\boxed{0}
\end{bmatrix}
```

此时消元就完全失效了。

接下来我们还是回到消元有效的情况，来继续解释回代。

此时就需要再对 $b$ 进行同等处理。

```math
\left[
\begin{array}{ccc|c}
1&2&1&2\\
3&8&1&12\\
0&4&1&2
\end{array}
\right]
\xrightarrow{(2,1)}
\left[
\begin{array}{ccc|c}
1&2&1&2\\
0&2&-2&6\\
0&4&1&2
\end{array}
\right]
```

再进行：

```math
\xrightarrow{(3,2)}
\left[
\begin{array}{ccc|c}
1&2&1&2\\
0&2&-2&6\\
0&0&5&-10
\end{array}
\right]
```

$A$ 再加上向量 $b$ 的叫做增广矩阵，“增广”其实就是增加新列的意思。

经过消元后的 $b$ ，即：

```math
(2,6,-10)
```

被记为 $C$ 。

$C$ 是 $b$ 的最终结果，就像 $U$ 对于 $A$ 一样。

再将：

```math
\left[
\begin{array}{ccc|c}
1&2&1&2\\
0&2&-2&6\\
0&0&5&-10
\end{array}
\right]
```

转述为方程，或者说：

```math
Ux=C
```

即：

```math
\begin{cases}
x+2y+z=2\\
2y-2z=6\\
5z=-10
\end{cases}
```

所以：

```math
x=2,\qquad y=1,\qquad z=-2
```

---

接下来进入本讲的第二部分。

我们将真正使用矩阵语言来描述之前的消元变换。之前我们只是将矩阵作为一种简记手段。

我们该如何对矩阵

```math
\begin{bmatrix}
1&2&1\\
3&8&1\\
0&4&1
\end{bmatrix}
```

进行操作，使之得出

```math
\begin{bmatrix}
1&2&1\\
0&2&-2\\
0&4&1
\end{bmatrix}
```

好吧，或许直接问有些太突兀了。先让我们回顾一下上节课说的内容。

之前我们说过所谓的“大图”。

当矩阵左乘列向量，其结果其实是矩阵列的线性组合。

例如：

```math
\begin{bmatrix}
2&5\\
1&3
\end{bmatrix}
\begin{bmatrix}
1\\
2
\end{bmatrix}
=
1
\begin{bmatrix}
2\\
1
\end{bmatrix}
+
2
\begin{bmatrix}
5\\
3
\end{bmatrix}
=
\begin{bmatrix}
12\\
7
\end{bmatrix}
```

> 注意:右乘行向量可不是像上面这样算的。

但现在我们进行的是列变换吗？

不是的，很明显这是行变换：

> 2 行减去 3 个 1 行。

所以应该是左乘一个矩阵，作行的线性组合：

```math
\boxed{\phantom{
\begin{matrix}
1&0&0\\
0&1&0\\
0&0&1
\end{matrix}
}}
\begin{bmatrix}
1&2&1\\
3&8&1\\
0&4&1
\end{bmatrix}
=
\begin{bmatrix}
1&2&1\\
0&2&-2\\
0&4&1
\end{bmatrix}
```

例如对于

```math
[\,1\quad2\quad7\,]
\begin{bmatrix}
\text{—— 第一行 ——}\\
\text{—— 第二行 ——}\\
\text{—— 第三行 ——}
\end{bmatrix}
```

来说，结果的第一行是：

> 1 个第一行，2 个第二行，7 个第三行相加之后得到的。

所以现在要寻找：

```math
\boxed{?}
\begin{bmatrix}
1&2&1\\
3&8&1\\
0&4&1
\end{bmatrix}
=
\begin{bmatrix}
1&2&1\\
0&2&-2\\
0&4&1
\end{bmatrix}
```

对于第一行来说，就是之前的第一行，所以左乘的矩阵第一行就是：

```math
[\,1\quad0\quad0\,]
```

结果的第三行是：

```math
0\text{ 个一行}+0\text{ 个二行}+1\text{ 个三行}
```

即：

```math
[\,0\quad0\quad1\,]
```

而结果的第二行是原来第二行减去 3 个第一行，所以是：

```math
[\,-3\quad1\quad0\,]
```

即：

```math
\begin{bmatrix}
1&0&0\\
-3&1&0\\
0&0&1
\end{bmatrix}
\begin{bmatrix}
1&2&1\\
3&8&1\\
0&4&1
\end{bmatrix}
=
\begin{bmatrix}
1&2&1\\
0&2&-2\\
0&4&1
\end{bmatrix}
```

当然，这里插入一下。

对于一个矩阵，如果其左乘一个矩阵 $A$ ，得到的仍旧是 $A$ ，这就意味着这个矩阵是：

```math
\begin{bmatrix}
1&0&0\\
0&1&0\\
0&0&1
\end{bmatrix}
```

数学语言表述是：

```math
IA=A
```

前面已经知道，单位矩阵 $I$ 左乘 $A$ 时不会改变 $A$ ，因此可以把 $I$ 看作一种“什么操作都没有记录”的初始状态。

而在实际消元中，$A\to U$ 并不是一步完成的，而是由若干个初等行变换组成。对于其中某一个子过程，如果把同样的行变换施加到单位矩阵 $I$ 上，就会得到一个新的矩阵 $E$ 。

这个 $E$ 就相当于把这一小步行变换记录了下来。之后用它左乘 $A$ ，就可以在 $A$ 上重新执行同样的操作：

```math
EA=A_1
```

因此，这种由单位矩阵经过一次初等行变换得到，并能够表示这一变换过程的矩阵，就称为初等矩阵。

如：

```math
\begin{bmatrix}
1&2&1\\
3&8&1\\
0&4&1
\end{bmatrix}
\longrightarrow
\begin{bmatrix}
1&2&1\\
0&2&-2\\
0&4&1
\end{bmatrix}
```

是 2 行减 3 个 1 行的结果。

那么单位矩阵：

```math
\begin{bmatrix}
1&0&0\\
0&1&0\\
0&0&1
\end{bmatrix}
```

执行同等变换，就有：

```math
\begin{bmatrix}
1&0&0\\
-3&1&0\\
0&0&1
\end{bmatrix}
```

由于：

```math
\begin{bmatrix}
1&0&0\\
-3&1&0\\
0&0&1
\end{bmatrix}
\begin{bmatrix}
1&2&1\\
3&8&1\\
0&4&1
\end{bmatrix}
=
\begin{bmatrix}
1&2&1\\
0&2&-2\\
0&4&1
\end{bmatrix}
```

消去了 $(2,1)$ 。

所以我们把初等矩阵：

```math
E=
\begin{bmatrix}
1&0&0\\
-3&1&0\\
0&0&1
\end{bmatrix}
```

记为：

```math
E_{21}
```

之后我们来看下一步：

```math
\begin{bmatrix}
1&2&1\\
0&2&-2\\
0&4&1
\end{bmatrix}
\longrightarrow
\begin{bmatrix}
1&2&1\\
0&2&-2\\
0&0&5
\end{bmatrix}
```

三行减 2 个二行。

所以：

```math
E_{32}
=
\begin{bmatrix}
1&0&0\\
0&1&0\\
0&-2&1
\end{bmatrix}
```

所以对于 $A\to U$ 的整个进程就是：

```math
E_{32}(E_{21}A)=U
```

显然是，我们知道矩阵有结合律，所以如果想要让 $A$ 一步到 $U$ ，只需要 $E_{32}\cdot E_{21}$ 就行：

```math
(E_{32}E_{21})A=U
```

---

既然这里谈到了初等矩阵，就不得不提到另一类初等矩阵——让两行交换的，叫置换矩阵。

这里也很好理解。

比如想让：

```math
\begin{bmatrix}
a&b\\
c&d
\end{bmatrix}
```

变成：

```math
\begin{bmatrix}
c&d\\
a&b
\end{bmatrix}
```

只需要左乘：

```math
\begin{bmatrix}
0&1\\
1&0
\end{bmatrix}
```

它被记为 $P$ ，$P$ 是置换的意思。

如果要进行列处理——当然今天我们对于列处理讲得很少，消元里面用的都是行处理，用不到列处理，但我们还是要稍微提一下——那首先当然不能用左乘，必须是右乘才行。

```math
\begin{bmatrix}
a&b\\
c&d
\end{bmatrix}
\boxed{?}
=
\begin{bmatrix}
b&a\\
d&c
\end{bmatrix}
```

答案是：

```math
\begin{bmatrix}
0&1\\
1&0
\end{bmatrix}
```

我们要一列一列看。

第一列是：

```math
\begin{bmatrix}
0\\
1
\end{bmatrix}
```

表示原来 0 个第一列加上原来 1 个第二列，所以就变成：

```math
\begin{bmatrix}
b\\
d
\end{bmatrix}
```

相信：

```math
\begin{bmatrix}
1\\
0
\end{bmatrix}
```

不用我说了。

左乘是行变换，右乘是列变换，所以显然先后顺序不可以随便交换，数学意义就会不同。

之前我们说到，如果想让 $A$ 一步变 $U$ ，可以左乘：

```math
E_{32}E_{21}
```

但其实，还有更好的做法。

这个方法不是关于 $A$ 如何变 $U$ ，而是 $U$ 如何变 $A$ 。

下面将进行逆变换，这是我们了解逆矩阵的第一步。

今天的例子矩阵都可逆，它们是让人舒服的矩阵，没遇到过消元失效的情况。

对于初等矩阵：

```math
E_{21}
=
\begin{bmatrix}
1&0&0\\
-3&1&0\\
0&0&1
\end{bmatrix}
```

它表示：

> 用 1 个二行减去 3 个一行。

所以逆就是：

> 用 1 个二行加上 3 个一行。

这就是 $E_{21}$ 的逆矩阵：

```math
E_{21}^{-1}
=
\begin{bmatrix}
1&0&0\\
3&1&0\\
0&0&1
\end{bmatrix}
```

于是：

```math
\begin{bmatrix}
1&0&0\\
3&1&0\\
0&0&1
\end{bmatrix}
\begin{bmatrix}
1&0&0\\
-3&1&0\\
0&0&1
\end{bmatrix}
=
\begin{bmatrix}
1&0&0\\
0&1&0\\
0&0&1
\end{bmatrix}
```

简记为：

```math
E^{-1}E=I
```
