# 线性组合中系数和为 1 的几何意义

在做《线性代数导论》第五版习题时，我注意到一个很有意思的现象。

对于两个二维向量 $v,w$，考虑它们的线性组合

```math
u=cv+dw.
```

如果不对 $c,d$ 做任何限制，那么 $u$ 会随着两个标量的变化在由 $v,w$ 张成的范围内移动。

但是，如果额外限制

```math
c+d=1,
```

现象会突然变得非常规整：

> 无论怎样改变 $c,d$，只要始终满足 $c+d=1$，那么 $u=cv+dw$ 所描述的点就始终落在经过 $v,w$ 两点的同一条直线上。

为了确认这不是某几个数值碰巧产生的现象，我做了一个 Plotly 交互网页。这里的分工也很明确：我先和 ChatGPT 把数学目标、交互方式和项目需求说清楚，再把明确后的需求交给 Codex 实现代码。生成的网页通过 VS Code 端口转发在本地浏览器中运行，因此可以直接拖动系数观察现象，而不是只看一张静态图。

## 为什么一定在这条直线上

条件是

```math
c+d=1.
```

因此

```math
d=1-c.
```

代入原来的线性组合

```math
u=cv+dw,
```

得到

```math
u=cv+(1-c)w.
```

整理：

```math
u=w+c(v-w).
```

这一步非常关键。

原来的式子

```math
u=cv+dw
```

看起来只是两个向量分别乘上标量之后再相加。

但是在加入 $c+d=1$ 这个条件以后，它可以改写成

```math
\boxed{u=w+c(v-w)}.
```

这时几何结构就很清楚了：

- $w$ 是一个固定点；
- $v-w$ 是一个固定方向；
- $c$ 是唯一可以自由变化的参数。

也就是说：

> 从 $w$ 出发，沿着 $v-w$ 的方向走 $c$ 倍的距离。

因此所有可能的 $u$ 都属于

```math
\left\{\,w+t(v-w)\mid t\in\mathbb R\,\right\}.
```

这正是经过 $w$ 和 $v$ 的直线的参数形式。

所以这里并不是某种数值巧合，而是条件

```math
c+d=1
```

把原本的

```math
cv+dw
```

强制改写成了

```math
\text{固定点}+\text{标量}\times\text{固定方向}.
```

这就解释了为什么交互图中，无论怎样拖动，只要锁定 $c+d=1$，点 $u$ 都像被一条轨道限制住一样，只能沿同一条直线运动。

---

## 标量变化时，点具体跑到哪里

继续看

```math
u=w+c(v-w).
```

当 $c=0$ 时，

```math
u=w.
```

当 $c=1$ 时，

```math
u=v.
```

当

```math
c=\frac12
```

时，

```math
u=\frac12v+\frac12w,
```

正好位于 $v,w$ 的中点。

例如：

```math
c=\frac14,\qquad d=\frac34,
```

那么

```math
u
=
\frac14v+\frac34w
=
w+\frac14(v-w).
```

也就是说，从 $w$ 向 $v$ 走四分之一。

而当

```math
c=\frac34,\qquad d=\frac14
```

时，

```math
u=w+\frac34(v-w),
```

所以点已经走到了从 $w$ 到 $v$ 的四分之三处。

因此，当

```math
0\le c\le1
```

时，由于

```math
d=1-c\ge0,
```

点 $u$ 会被限制在 $v,w$ 之间的线段上。

但是，如果继续把滑块往外拖：

当 $c>1$ 时，

```math
d=1-c<0,
```

此时点会越过 $v$，继续落在同一条直线的延长线上。

当 $c<0$ 时，点则会越过 $w$，向另一侧延伸。

所以这个现象可以分成两层：

```math
\boxed{c+d=1}
```

保证 $u$ 位于经过 $v,w$ 的整条直线上；

进一步要求

```math
\boxed{c,d\ge0,\qquad c+d=1}
```

则会把范围进一步限制到 $v,w$ 之间的线段。

---

## 我现在对这个现象的理解

一开始看到

```math
u=cv+dw
```

时，我只是把它理解为“两个向量分别乘标量之后再相加”。

但加入

```math
c+d=1
```

以后，它的结构发生了一个很值得注意的变化：

```math
cv+dw=w+c(v-w).
```

左边还是“两个向量的线性组合”，右边却已经完全变成了几何意义上的

```math
\text{点}+\text{方向}.
```

所以系数和等于 $1$ 的意义，不只是两个数字之间多了一个约束。

更本质地说，它把两个可以自由变化的标量压缩成了一个自由参数，同时把所有结果限制到一条直线上。

从交互图来看，这个变化尤其明显：

- $c,d$ 自由变化时， $u$ 可以在更大的范围内移动；
- 一旦锁定 $c+d=1$， $u$ 立刻只能沿一条直线移动；
- 再限制 $c,d\ge0$，移动范围进一步缩成一条线段。

这种“先观察现象，再从代数形式中解释几何原因”的方式，比单纯记住一个结论直观得多。

## 术语补充

以后会给这些结构正式命名。

满足

```math
c+d=1
```

的组合

```math
cv+dw
```

属于“仿射组合”的典型形式。

如果进一步满足

```math
c,d\ge0,
```

那么它又属于“凸组合”。

现在没有必要先背这些名字。对我来说，更重要的是先记住它们背后的结构：

```math
\boxed{
c+d=1
\Longrightarrow
cv+dw=w+c(v-w)
}
```

以及它对应的几何意义：

```math
\boxed{
\text{固定点}+\text{标量}\times\text{固定方向}
}
```

这才是这次实验真正揭示出来的东西。
