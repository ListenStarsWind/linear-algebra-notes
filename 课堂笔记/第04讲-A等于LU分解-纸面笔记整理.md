# 第04讲：A = LU 分解

## 乘积的逆矩阵是什么

如果把两个矩阵相乘，而且知道它们各自的逆矩阵，怎样求出整个乘积的逆矩阵？

这个问题其实很简单。假设 A 和 B 都是可逆方阵，那么：

```math
(AB)^{-1}=B^{-1}A^{-1}.
```

这里值得注意的是顺序：先做的事情，最后撤销。我们直接把它们乘起来，就能看到原因：

```math
\begin{aligned}
(AB)(B^{-1}A^{-1}) &=A(BB^{-1})A^{-1} \\
&=AIA^{-1} \\
&=I.
\end{aligned}
```

另一边也一样：

```math
\begin{aligned}
(B^{-1}A^{-1})(AB) &=B^{-1}(A^{-1}A)B \\
&=B^{-1}IB \\
&=I.
\end{aligned}
```

整个过程只改变了乘法的结合方式，没有交换矩阵的位置。

顺便再说说转置。下一讲会经常遇到它：如果把一个可逆方阵转置，那么转置后的逆矩阵是什么？

答案也是一个很漂亮的公式：

```math
(A^T)^{-1}=(A^{-1})^T.
```

我们从 AA⁻¹=I 出发，把两边同时转置。单位矩阵转置后还是单位矩阵；而乘积的转置，需要把各个矩阵转置，并反过来排列：

```math
(AB)^T=B^TA^T.
```

于是：

```math
(AA^{-1})^T=(A^{-1})^TA^T=I.
```

也可以从 A⁻¹A=I 得到：

```math
A^T(A^{-1})^T=I.
```

这就说明 (A⁻¹)ᵀ 正是 Aᵀ 的逆矩阵。对于单个可逆方阵，先转置再求逆，或者先求逆再转置，结果相同。

## 从消元走到 A = LU

下面再谈一下消元，这次从矩阵角度来理解。它为我们提供了一条理解矩阵结构的途径，而 A=LU 就是其中一种基本分解。

先假设矩阵 A 的消元过程十分顺利：各个主元都非零，不需要交换行。最后得到上三角矩阵 U 。我们已经知道怎样从 A 走到 U ，接下来要看它们之间的关系。

### 先看二阶方阵

令：

```math
A=
\begin{bmatrix}
2&1\\
8&7
\end{bmatrix}.
```

首先要找到初等消元矩阵 E₂₁ ，把第 (2,1) 个元素消去。显然，可以用第二行减去第一行的四倍：

```math
\begin{aligned}
E_{21}A&=
\begin{bmatrix}
1&0\\
-4&1
\end{bmatrix}
\begin{bmatrix}
2&1\\
8&7
\end{bmatrix}\\
&=
\begin{bmatrix}
2&1\\
0&3
\end{bmatrix}
=U.
\end{aligned}
```

由于矩阵只有两阶，一步就得到了 U 。不过，接下来想换一个形式：让 A 单独放在等式一边，其余矩阵放在另一边。

一方面，可以在等式两边左乘 E₂₁⁻¹ ；另一方面，也可以直接想：刚才从第二行减去了第一行的四倍，那么要从 U 回到 A ，就把第一行的四倍加回来。

因此：

```math
A=E_{21}^{-1}U=
\begin{bmatrix}
1&0\\
4&1
\end{bmatrix}
\begin{bmatrix}
2&1\\
0&3
\end{bmatrix}.
```

把前面的矩阵记作 L ，就得到了：

```math
A=LU.
```

L 表示下三角， U 表示上三角。这里 L 的对角线元素都是 1 ，而 U 的对角线上是消元得到的主元。

说到主元，还有一种写法：把它们单独提出来，组成对角矩阵 D 。在这个例子中：

```math
A=
\begin{bmatrix}
1&0\\
4&1
\end{bmatrix}
\begin{bmatrix}
2&0\\
0&3
\end{bmatrix}
\begin{bmatrix}
1&\frac12\\
0&1
\end{bmatrix}.
```

这就是 LDU 分解。为了区分，原来的上三角矩阵可以写成 U=DÛ ，这里最后一个矩阵就是 Û 。它和 L 的对角线上都是 1 ，主元集中放在中间的 D 里。

### 三阶矩阵能看出什么

二阶矩阵的规模太小，只能走过这个过程，还不太容易看出为什么偏爱 A=LU 这种形式。接下来看看三阶情况。

三阶矩阵主元下方有三个位置需要处理，分别对应 E₂₁ 、 E₃₁ 和 E₃₂ 。在不交换行的情况下：

```math
E_{32}E_{31}E_{21}A=U.
```

最先作用的是紧挨着 A 的 E₂₁ ，然后是 E₃₁ ，最后是 E₃₂ 。如果某个位置本来就是零，对应步骤可以省略。

仍然把它改写成 A=LU 的形式：

```math
A=E_{21}^{-1}E_{31}^{-1}E_{32}^{-1}U.
```

所以：

```math
L=E_{21}^{-1}E_{31}^{-1}E_{32}^{-1}.
```

为什么更喜欢 A=LU ，而不是 EA=U ？或者说，和 E 相比， L 好在哪里？

现在假设：

```math
\begin{aligned}
E_{21}&=
\begin{bmatrix}
1&0&0\\
-2&1&0\\
0&0&1
\end{bmatrix},\\
E_{31}&=I,\\
E_{32}&=
\begin{bmatrix}
1&0&0\\
0&1&0\\
0&-5&1
\end{bmatrix}.
\end{aligned}
```

也就是说，先从第二行减去第一行的两倍；第 (3,1) 个位置已经是零，不必处理；然后从第三行减去新的第二行的五倍。

把这些操作合起来，得到整体消元矩阵：

```math
\begin{aligned}
E&=E_{32}E_{31}E_{21}\\
&=E_{32}E_{21}\\
&=
\begin{bmatrix}
1&0&0\\
-2&1&0\\
10&-5&1
\end{bmatrix}.
\end{aligned}
```

让我们在意的是这里的 10 ：它是怎么来的？

假设原来的三行分别是 R₁,R₂,R₃ 。第一步得到的新第二行是：

```math
R_2'=R_2-2R_1.
```

接着第三行变为：

```math
\begin{aligned}
R_3'&=R_3-5R_2' \\
&=R_3-5(R_2-2R_1) \\
&=R_3-5R_2+10R_1.
\end{aligned}
```

于是，第一行通过新的第二行间接影响了第三行，整体矩阵中就出现了 10 。这个数是正确的，只是它已经把几步操作的影响合在一起了。

现在再来看 L 。对于这里每一个单独的初等消元矩阵，求逆很简单：减去某一行的若干倍，逆操作就是把那些倍数加回来，因此相应位置变号。

但整个乘积求逆时，除了分别求逆，还必须反转顺序：

```math
\begin{aligned}
L&=E_{21}^{-1}E_{32}^{-1}\\
&=
\begin{bmatrix}
1&0&0\\
2&1&0\\
0&0&1
\end{bmatrix}
\begin{bmatrix}
1&0&0\\
0&1&0\\
0&5&1
\end{bmatrix}\\
&=
\begin{bmatrix}
1&0&0\\
2&1&0\\
0&5&1
\end{bmatrix}.
\end{aligned}
```

这次没有冒出一个像 10 那样的新数。原来使用的消元乘数 2 和 5 ，直接出现在了 L 的对应位置上。

这就是一个直观的区别： E 记录合起来的消元效果，而 L 的下三角部分直接记录我们用了哪些消元乘数。在这里约定的消元顺序下，只要不交换行，这个规律就可以继续使用。

因此，生成 U 时，也可以顺手把消元乘数存进 L ，不用事后真的把一串逆矩阵乘起来。

这里也不是说整个过程的信息丢了。 L 保存消元乘数， U 保存消元后的结果，二者合起来可以恢复 A 。我们可以用 L,U 代替原来的 A 来保存这些信息。

## 消元的计算量有多大

接下来讨论一个实际问题：对于一个 n× n 的矩阵，需要多少运算才能完成消元？

在一些应用中，我们会希望 n 更大，因为更大的矩阵可以表达更多信息，或者把问题描述得更细。不过，规模越大，计算代价也越高。关键是：这个代价随 n 增长得有多快？

是与 n 成正比，是 n² 、 n³ 这样的多项式增长，还是 n! 这样的阶乘增长？

### 为什么第一阶段约为 100²

先假设有一个 100×100 的矩阵 A ，并且没有可以省掉大量计算的特殊零元素。

我们先看第一阶段：用第一行，把第一列主元下方的元素清零。

对于下面任意一行，需要先求一个消元乘数，再执行：

```math
R_i\leftarrow R_i-\ell_{i1}R_1.
```

这句话写起来只有一步，但一行里有 100 个元素。因此，第一行乘上这个系数，需要约 100 次乘法；对应行减去乘好的第一行，又需要约 100 次减法。

这里沿用课堂的计数方式：把一次乘法和紧接着的一次减法合计为一组操作。于是，处理一行需要约 100 组操作。

下面有 99 行要处理，大致按 100 行估算，所以第一阶段的计算量约为：

```math
100\times100=100^2.
```

两个 100 的来源不同：一个是约有 100 行需要处理，另一个是每行约有 100 个元素需要更新。

求消元乘数还需要除法，不过这些计算不会改变后面得到的最高次项，这里先不细数。

第一阶段结束后，第一行和第一列已经处理好了。接下来只需要在剩下的 99×99 部分重复这个过程，计算量约为 99² 。再往后是 98² ，依此类推。

所以总计算量可以近似写成：

```math
\begin{aligned}
\sum_{k=1}^{n}k^2 &=n^2+(n-1)^2+\cdots+1^2.
\end{aligned}
```

这里的平方和只是对消元次数的近似计数；每个阶段并不真的恰好做了对应数量的操作。

### 平方和怎样求出来

令：

```math
S=1^2+2^2+\cdots+n^2.
```

我们知道：

```math
(k+1)^3-k^3=3k^2+3k+1.
```

令 k 依次取 1,2,…,n ，就得到 n 个等式。例如：

```math
\begin{aligned}
2^3-1^3&=3\cdot1^2+3\cdot1+1,\\
3^3-2^3&=3\cdot2^2+3\cdot2+1,\\
4^3-3^3&=3\cdot3^2+3\cdot3+1,\\
&\ \vdots\\
n^3-(n-1)^3&=3(n-1)^2+3(n-1)+1,\\
(n+1)^3-n^3&=3n^2+3n+1.
\end{aligned}
```

把这些等式加起来，左边中间的立方项互相抵消，只剩：

```math
\begin{aligned}
(n+1)^3-1 &=3S+3(1+2+\cdots+n)+n.
\end{aligned}
```

利用等差数列的求和公式：

```math
1+2+\cdots+n=\frac{n(n+1)}2,
```

就有：

```math
\begin{aligned}
3S
&=(n+1)^3-1-\frac{3n(n+1)}2-n\\
&=n^3+3n^2+2n-\frac{3n(n+1)}2.
\end{aligned}
```

整理得到：

```math
\begin{aligned}
S&=\frac{n^3}{3}+\frac{n^2}{2}+\frac n6 \\
&=\frac{n(n+1)(2n+1)}6.
\end{aligned}
```

这个平方和公式是精确的。对于前面消元计算量的近似估算，主要看最高次项，所以得到约 n³/3 组乘减操作。

如果把乘法和减法分别计数，最高次项约为 2n³/3 。常数不同，但都属于 n³ 级别。

## 等号右边的数需要多少计算

前面只算了对系数矩阵 A 消元的代价。但解一个方程组，等号右边的数也要跟着做相同的行操作。

方程组可以写成 Ax=b 。其中， A 是系数矩阵， x 是未知数向量， b 是等号右边的数排成的列向量。例如：

```math
\begin{bmatrix}
2&1\\
8&7
\end{bmatrix}
\begin{bmatrix}
x_1\\
x_2
\end{bmatrix}
=
\begin{bmatrix}
5\\
13
\end{bmatrix}.
```

把 b 接在 A 旁边，就得到增广矩阵。左边第二行减去第一行的四倍，右边也必须做 13-4×5 。

现在回到 n 阶的情况。由于 b 只有一列，每次行操作只需要更新右端的一个数：

```math
b_i\leftarrow b_i-\ell_{i1}b_1.
```

第一阶段需要更新 n-1 个右端数，第二阶段需要更新 n-2 个，依此类推。于是，右端项跟着消元的计算量是：

```math
\begin{aligned}
(n-1)+(n-2)+\cdots+1 &=\frac{n(n-1)}2.
\end{aligned}
```

它已经是 n² 级别，但这时还没有求出全部未知数。

消元结束后，还需要从最后一行开始回代。最后一个未知数可以直接求出；倒数第二行需要减去一个已知项；再上一行需要减去两个已知项。一直往上，乘减操作的数量也是：

```math
\begin{aligned}
0+1+2+\cdots+(n-1) &=\frac{n(n-1)}2.
\end{aligned}
```

把消元时处理右端项的操作、回代的操作，以及求出各个未知数时的 n 次除法合起来，按照这里的计数口径：

```math
\frac{n(n-1)}2+\frac{n(n-1)}2+n=n^2.
```

所以，系数矩阵消元完成后，每组右端项的处理加上回代，计算量约为 n² 。

和处理 A 的区别就在这里： A 每行有很多元素，每次行操作要更新一整行；而 b 只有一列，每次行操作只更新一个右端数。

## 分解一次，为什么能够省计算

如果只解一个方程组，把计算过程写成 LU 并不会凭空减少这些操作。真正能够省计算的情况是：同一个系数矩阵，要处理多组不同的右端项。

例如：

```math
\begin{aligned}
Ax_1&=b_1,\\
 Ax_2&=b_2,\\
 Ax_3&=b_3.
\end{aligned}
```

它们的系数矩阵 A 完全相同，只是右端项不同，求出的解也一般不同。

先把 A 分解为 LU ，就可以把这些方程组写成：

```math
\begin{aligned}
LUx_1&=b_1,\\
 LUx_2&=b_2,\\
 LUx_3&=b_3.
\end{aligned}
```

这里并不是说换一种写法就减少了计算，而是把相同的工作保存下来，之后不再重复做。

对每一组右端项，可以先把 Uxᵢ 暂时记为 yᵢ ，于是依次求解：

```math
Ly_i=b_i,\qquad Ux_i=y_i.
```

L 和 U 都是三角矩阵。前一个从上往下求解，后一个从下往上回代，合计约 n² 组操作，不需要重新对原来的 A 消元，也不需要显式求逆。

假设有 m 组右端项，如果每一组都从头对增广矩阵消元，再回代，总计算量约为：

```math
m\left(\frac{n^3}{3}+n^2\right).
```

如果只分解一次，然后重复使用 L,U ，总计算量约为：

```math
\frac{n^3}{3}+mn^2.
```

省掉的是重复进行的那 m-1 次矩阵分解。

从自己手算的角度看，这其实也符合直觉：既然各个方程组的系数完全相同，我们也不会每次都重新处理 A ，而是保留已经做好的消元结果，让不同的右端项按照相同规则变化。 LU 分解把这件事明确地记录成了两个矩阵。

## 如果需要交换行

上面讨论的消元都不交换行。那么，如果主元位置出现零，需要交换行，该怎样用矩阵表示？

这就引出了置换矩阵 P 。我们先以三阶单位矩阵为例，通过重新排列它的行，得到一组置换矩阵。

单位矩阵本身也包括在内，因为“不改变任何行”同样是一种置换：

```math
I=
\begin{bmatrix}
1&0&0\\
0&1&0\\
0&0&1
\end{bmatrix}.
```

如果只交换一对行，有三种可能：

```math
\begin{aligned}
P_{12}&=
\begin{bmatrix}
0&1&0\\
1&0&0\\
0&0&1
\end{bmatrix},\\
P_{13}&=
\begin{bmatrix}
0&0&1\\
0&1&0\\
1&0&0
\end{bmatrix},\\
P_{23}&=
\begin{bmatrix}
1&0&0\\
0&0&1\\
0&1&0
\end{bmatrix}.
\end{aligned}
```

还有两种循环置换：

```math
\begin{aligned}
C&=
\begin{bmatrix}
0&1&0\\
0&0&1\\
1&0&0
\end{bmatrix},\\
Q&=
\begin{bmatrix}
0&0&1\\
1&0&0\\
0&1&0
\end{bmatrix}.
\end{aligned}
```

左乘 C 时，原来的第二行成为第一行，第三行成为第二行，第一行成为第三行。左乘 Q 时，循环方向反过来。

加上单位矩阵，一共六种。这也可以从各行的选择数看出来：每行、每列都恰好有一个 1 ，其余位置都是 0 。第一行中 1 的位置有三种选择；选完后，第二行有两种；最后一行只有一种。因此：

```math
3\times2\times1=6.
```

更一般地， n 阶置换矩阵共有 n! 个。所以四阶的情况有 4!=24 个。

这里讨论的是左乘矩阵来重排行。右乘置换矩阵可以重排列；两种操作的位置和作用不同，应在表达式中说明清楚。

### 相乘与求逆有什么特点

任取这六个矩阵中的两个相乘，得到的仍然是其中一个。

原因很直观：先做一次行重排，再做一次行重排，合起来仍然是行重排。而我们已经把三行的全部排列方式列出来了，因此结果不会跑到这六种之外。

这组矩阵中包含单位矩阵；每个矩阵的逆，也仍在这组矩阵中。因为把一组行重排恢复原位，做的还是行重排。结合矩阵乘法的结合律，它们组成一个群。

特别地，如果两个置换矩阵的乘积是 I ，它们就互为逆矩阵。

下面三个两行交换矩阵的逆都是自身：

```math
\begin{aligned}
P_{12}^{-1}&=P_{12},\\
P_{13}^{-1}&=P_{13},\\
P_{23}^{-1}&=P_{23}.
\end{aligned}
```

因为把同一对行再交换一次，就回到了原来的顺序。单位矩阵的逆当然也还是它自己。

两个循环置换矩阵则互为逆：

```math
C^{-1}=Q,\qquad Q^{-1}=C.
```

置换矩阵还有一个统一的性质：

```math
P^{-1}=P^T.
```

转置后的置换矩阵恰好能够撤销原来的重排。因此，不是所有置换矩阵都等于自身的逆，但它们的逆都等于各自的转置。
