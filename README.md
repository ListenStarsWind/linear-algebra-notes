# 线性代数学习笔记

这是我的线性代数学习仓库。

目前以 Gilbert Strang 的 MIT 18.06《Linear Algebra》真实课堂录像为主线学习，使用中文字幕版本，并结合中文资料整理自己的理解、推导、例题与可视化图像。

这个仓库不只是保存课堂笔记，也希望逐步建立一套可复现的数学可视化工作流：

> 数学对象 / 方程 / 参数
> → Python 计算与绘图
> → SVG 静态图像 + HTML 交互式图像
> → 嵌入 Markdown 笔记

重点不是单纯保存截图，而是尽可能保存“图像是怎样生成的”。

## 仓库设计原则

### 1. 中文优先

只要工具没有强制要求，目录名、文件名、参数名以及笔记内容尽量使用中文。

例如：

```text
第01讲-方程组的几何解释.md
第01讲-行图像-三维.yaml
绘制三维行图像.py
```

以下名称由于属于工具约定或通用项目文件，保留英文：

```text
README.md
requirements.txt
.gitignore
.venv
.git
```

文件名尽量不使用空格，中文词组之间使用 `-` 分隔。

------

### 2. 参数与代码是源文件

数学图像不应该只是一次性的截图。

例如一个三元线性方程组：

```text
x + y + z = 6
2x - y + z = 3
x + 2y - z = 2
```

将首先保存为参数文件，再由 Python 读取参数并生成图像。

基本关系：

```text
图像参数/*.yaml
        +
绘图脚本/*.py
        │
        ▼
      Python
     ┌────┴────┐
     ▼         ▼
静态图像/    交互图像/
*.svg        *.html
```

这样即使以后删除生成结果，只要参数和代码仍然存在，图像就可以重新生成。

------

### 3. 静态图像与交互图像同时保留

数学笔记主要使用 SVG。

例如：

```markdown
![三元线性方程组的行图像](../静态图像/第01讲-行图像-三维.svg)
```

SVG 用于：

- Markdown 正式笔记
- GitHub 页面显示
- 长期保存
- 无损缩放

对于三维图像，则额外生成 HTML 版本。

HTML 用于：

- 鼠标旋转
- 缩放
- 从不同方向观察空间结构
- 帮助建立三维几何直觉

Markdown 负责保存知识，交互式 HTML 负责探索图像。

## 图像参数

图像所表达的数学对象尽量保存在 YAML 中。

例如：

```yaml
名称: 第01讲-三元方程组行图像

方程组:
  - 系数: [1, 1, 1]
    常数: 6

  - 系数: [2, -1, 1]
    常数: 3

  - 系数: [1, 2, -1]
    常数: 2

坐标范围:
  x: [-5, 5]
  y: [-5, 5]
  z: [-5, 5]

输出:
  静态图像: 静态图像/第01讲-行图像-三维.svg
  交互图像: 交互图像/第01讲-行图像-三维.html
```

Python 内部同样允许使用中文变量名或中文配置键，例如：

```python
配置["方程组"]
配置["坐标范围"]
```

第三方库本身的 API 保持原样：

```python
np.linalg.solve()
plt.savefig()
```
